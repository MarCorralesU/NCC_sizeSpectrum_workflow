# SPECTRA: code for calculating size spectrum based on ISIIS-3 and LISST data

## Overview

This is a repository for the code used to generate Normalized Biovolume size spectra calculations from ISIIS-3 (Cowen and Guigand, 2008) and LISST (Sequoia Instruments) data, following Dugenne et al. (2024)
